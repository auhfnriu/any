# 분실물 라디오 · Lost & Found Radio

잡음 사이에서 잃어버린 것들의 방송을 찾는 작은 인터랙티브 탐험입니다.
주파수와 안테나를 맞추면 메시지가 도착하고, 수신 기록이 한 장씩 채워집니다.

## 실행하기

1. ZIP으로 받았다면 압축을 풉니다.
2. **`index.html`을 최신 Microsoft Edge 또는 Google Chrome에서 여세요.**
3. 「자동 탐색」을 누르고, 오른쪽 **ANTENNA** 막대를 천천히 움직여 보세요.

HTML 파일 하나에 화면, 그림, 이야기, 소리가 모두 들어 있습니다.
설치, 서버, 인터넷, 계정, 결제, 외부 API 키가 필요하지 않습니다.

## 체험 방법

- **주파수 찾기:** 큰 다이얼을 위 또는 오른쪽으로 드래그하면 주파수가 올라갑니다. 반대로 드래그하면 내려갑니다. 화면 아래 주파수 막대나 `−` / `+` 버튼도 사용할 수 있습니다.
- **자동 탐색:** 아직 받지 못한 다음 신호까지 찾아갑니다. 한 번 더 누르면 멈춥니다.
- **안테나 맞추기:** 오른쪽 ANTENNA 막대로 각도를 조절하세요. 신호가 약하면 화면 아래에 방향 힌트가 나옵니다. 금속 안테나 자체도 드래그할 수 있습니다.
- **메시지 수신:** 신호가 **86% 이상**인 상태로 약 **2.4초**를 유지하면 이야기가 도착합니다. 소리를 켜지 않아도 수신됩니다.
- **기록 읽기:** 받은 이야기는 아래 수신 기록에서 다시 읽을 수 있습니다. 여섯 개를 모으면 새로운 신호를 찾을 수 있습니다.
- **일지 저장:** 수신한 이야기의 제목과 일부 문장을 담은 **1600 × 1600 PNG**를 저장합니다. 이 그림은 감상용이며, 진행 상황을 가져오는 파일은 아닙니다.
- **처음부터:** 확인 창을 거쳐 기록을 비웁니다. 필요하면 먼저 일지를 저장하세요.

모든 주파수는 가상의 방송입니다. 실제 라디오, 마이크, 위치 정보, 네트워크 방송을 사용하지 않습니다. 소리는 브라우저에서 직접 합성합니다.

## 키보드

| 키 | 기능 |
| --- | --- |
| `←` / `→` | 주파수 0.05 MHz 조절 |
| `↑` / `↓` | 안테나 1° 조절 |
| `Shift` + 방향키 | 10배 간격으로 조절 (슬라이더 외부에서) |
| `S` | 자동 탐색 시작 / 중지 |
| `M` | 소리 켜기 / 끄기 |
| `H` | 사용법 |
| `Esc` | 대화상자 닫기 |
| `Tab` | 조작 요소 사이 이동 |

슬라이더에 초점이 있으면 방향키는 그 슬라이더를 조절합니다. 주파수 다이얼에 초점이 있으면 위아래 방향키도 주파수를 조절합니다. 슬라이더와 다이얼에서 `Home` / `End`로 최솟값 / 최댓값에 갈 수 있습니다.

## 이어하기와 개인정보

받은 메시지와 마지막 주파수·안테나 위치는 같은 브라우저의 로컬 저장소에 자동 보관됩니다. 소리는 다시 열 때 꺼져 있습니다. 탐색 중 다른 탭으로 이동하면 자동 탐색을 멈춥니다.

파일을 옮기거나 브라우저를 바꾸면 이전 기록이 나타나지 않을 수 있습니다. 시크릿 모드, 저장소 차단, 브라우저 데이터 삭제 시 기록이 보존되지 않을 수 있습니다. 저장을 사용할 수 없어도 체험은 가능합니다.

외부 파일, 분석 도구, 쿠키, 개인정보 입력을 사용하지 않습니다. 모든 기록은 기기 안에만 남습니다.

키보드·마우스·터치를 지원하고, 운영체제의 「움직임 줄이기」 설정에서는 파형의 움직임을 줄입니다. 신호 상태와 수신 결과는 텍스트로도 표시됩니다.

## 파일

- `index.html` — 작품 전체. 이 파일만 있어도 실행됩니다.
- `README.md` — 실행 및 사용 안내.

HTML, CSS, Canvas 2D, Web Audio API로 제작했습니다. 그림과 소리는 코드로 생성합니다.

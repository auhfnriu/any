# 어제의 우체국 · Yesterday’s Post

어제의 나와 함께 오늘의 편지를 배달하는 작은 시간차 퍼즐입니다.
여섯 통의 편지, 두 개의 기억, 그리고 서두를 필요 없는 우체국.

## 실행

ZIP을 받았다면 압축을 풀고 **`index.html`을 더블클릭**하세요.
Windows의 최신 Microsoft Edge 또는 Google Chrome을 권장합니다.

HTML 파일 하나에 게임, 그림, 소리가 모두 들어 있습니다. 설치, 서버, 인터넷 연결, API 키, 회원 가입, 결제가 필요하지 않습니다.

## 배달하는 방법

1. 노란 봉투가 있는 칸으로 가서 편지를 집어 듭니다.
2. 편지를 들고 빨간 우편함으로 가면 배달 완료입니다.
3. 문이 잠겨 있다면 같은 숫자의 스위치를 찾으세요. 누군가 스위치 위에 서 있어야 문이 열립니다.
4. 스위치에 서서 **R**을 누르면, 지나온 길을 기억하는 「어제의 나」가 생기고 나는 출발점으로 돌아옵니다.
5. 내가 움직이거나 기다릴 때마다 기억도 예전 길을 한 칸씩 따라갑니다. 기억은 마지막 칸에 도착하면 그 자리에 계속 머물러 줍니다.
6. 기억이 스위치를 밟는 동안 문을 지나 배달을 계속하세요. 기억은 최대 두 개를 함께 둘 수 있습니다.

되감으면 들고 있던 편지도 원래 칸으로 돌아갑니다. 기억은 편지를 집지 않습니다.
세 번째 기억을 만들면 가장 오래된 기억이 교체됩니다. **Z**로 이 작업을 무를 수 있습니다.

시간은 행동할 때만 진행합니다. 제한 시간, 게임 오버, 유료 기능은 없습니다.
막혔을 때는 「작은 힌트」에서 단계별 안내를 볼 수 있습니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| 방향키 또는 WASD | 한 칸 이동 |
| 바닥 칸 클릭 / 터치 | 현재 갈 수 있는 길을 따라 자동 이동 |
| 화면 화살표 | 한 칸 이동 |
| Space 또는 「대기」 | 한 박자 기다리기 |
| R 또는 「이 길을 기억하고 되감기」 | 기억을 만들고 출발점으로 돌아가기 |
| Z 또는 「무르기」 | 직전 이동, 대기, 되감기, 재시작을 취소 |
| 「처음부터」 | 현재 배달을 처음부터 다시 시작 |
| M | 효과음 켜기 / 끄기 |
| H / Esc | 안내 열기 / 대화상자 닫기 |
| 아래쪽 우표 | 완료한 배달 및 다음 배달 선택 |

버튼에 키보드 초점이 있을 때 Space는 그 버튼을 실행합니다. 지도에 초점을 맞추면 Space로 기다릴 수 있습니다.
자동 이동은 키보드 조작이나 다른 칸 클릭으로 중단할 수 있습니다.

한 번의 기억은 최대 256걸음, 무르기는 최대 160행동입니다. 배달 완료 후에는 무르기 대신 다시 배달할 수 있습니다.

## 이어하기

현재 위치, 편지, 기억, 완료한 배달은 이 브라우저의 로컬 저장소에 자동 보관됩니다. 파일을 다시 열면 이어서 할 수 있습니다. 무르기 기록은 다시 열 때 초기화됩니다.

파일을 다른 폴더로 옮기거나 브라우저를 바꾸면 이전 진행이 보이지 않을 수 있습니다. 시크릿 모드, 저장소 차단, 브라우저 데이터 삭제 시 진행이 보존되지 않을 수 있습니다. 브라우저가 저장을 허용하지 않아도 게임은 실행됩니다.

## 접근성과 개인정보

- 키보드, 마우스, 터치 조작을 지원합니다.
- 스위치와 문은 색뿐 아니라 Ⅰ / Ⅱ 표기로 구분합니다.
- 운영체제의 「움직임 줄이기」 설정을 따릅니다.
- 효과음은 처음에는 꺼져 있으며, 브라우저에서 직접 합성합니다.
- 외부 파일 요청, 분석 도구, 쿠키, 개인정보 입력을 사용하지 않습니다.
- 시각적인 지도 퍼즐입니다. 상태 설명을 보조 기술에 알리지만, 지도 전체를 대신하는 비시각적 플레이 모드는 제공하지 않습니다.

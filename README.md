# 밤의 직조실 · The Night Loom

흐르는 빛에, 머물 자리를 만들어 주는 작은 인터랙티브 작품입니다.
손으로 그린 선은 별자리이자 악보가 되고, 작은 빛이 그 선을 여행하며 음악을 만듭니다.

## 실행하기

1. ZIP 파일로 받았다면 먼저 압축을 풉니다.
2. **`index.html`을 더블클릭**합니다. Windows의 최신 Microsoft Edge 또는 Google Chrome을 권장합니다.
3. 오른쪽 위 **「소리 켜기」**를 누르고, 화면 가운데를 천천히 드래그해 보세요.

HTML 파일 하나에 화면, 그림, 소리가 모두 들어 있습니다. 설치, 서버, 인터넷 연결, API 키, 회원 가입이 필요하지 않습니다. 소리는 브라우저에서 합성하며 처음에는 꺼져 있습니다.

## 체험하기

- **달빛 · 노을 · 꿈결**: 서로 다른 색과 음색의 실을 고릅니다.
- **드래그**: 자유로운 곡선으로 실을 엮습니다. 별의 높이가 음의 높이를 결정합니다.
- **짧게 클릭 / 터치**: 잠깐 피어나는 빛을 만듭니다.
- **세 가닥 엮기**: 밤의 손님이 찾아옵니다. 화면을 가로지르는 데 약 28초가 걸립니다. 이후에는 「손님 다시 부르기」로 부를 수 있습니다.
- **되돌리기**: 직전 실 또는 「새로운 밤」 작업을 되돌립니다. 최대 30단계이며, 파일을 다시 열면 되돌리기 기록은 초기화됩니다.
- **멈춤 / 재생**: 움직임과 음악을 잠시 멈춥니다.
- **새로운 밤**: 빈 하늘에서 다시 시작합니다. 되돌릴 수 있습니다.
- **이 밤 간직하기**: 현재 그림에 고유한 제목을 붙여 PNG 이미지로 저장합니다.

한 밤에 최대 24가닥을 엮을 수 있습니다. 점수, 제한 시간, 실패는 없습니다.

## 키보드

| 키 | 동작 |
| --- | --- |
| `1` / `2` / `3` | 실 선택 |
| `M` | 소리 켜기 / 끄기 |
| `Space` | 멈춤 / 재생 (버튼에 초점이 있으면 해당 버튼 실행) |
| `Ctrl+Z` / `⌘+Z` | 되돌리기 |
| `H` / `Esc` | 도움말 열기 / 닫기 |
| `Tab` | 캔버스와 버튼 사이 이동 |
| 방향키 | 캔버스에 초점이 있을 때 실을 놓을 위치 이동 |
| `Enter` | 캔버스에 초점이 있을 때 작은 고리 모양의 실 만들기 |

터치 화면에서는 손가락으로 그릴 수 있습니다. 운영체제의 「움직임 줄이기」 설정을 사용 중이면 처음에는 정지 상태로 열립니다. 재생 버튼으로 시작할 수 있습니다.

## 저장과 개인정보

작품은 같은 브라우저의 로컬 저장소에 자동 보관을 시도합니다. 브라우저를 바꾸거나 HTML 파일을 옮기면 이전 작품이 보이지 않을 수 있습니다. 시크릿 모드, 저장소 차단, 브라우저 데이터 삭제 시 자동 보관이 유지되지 않을 수 있으므로, 남기고 싶은 밤은 **PNG로 저장**하세요. PNG는 감상용이며 편집 가능한 파일은 아닙니다.

네트워크 요청, 분석 도구, 외부 글꼴, 쿠키, 개인정보 입력은 사용하지 않습니다. 자동 보관도 기기 안에서만 이루어집니다.
